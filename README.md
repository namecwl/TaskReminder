# 任务提醒 App

自用安卓任务提醒 App。到点弹通知，支持重复、提前提醒、稍后 5 分钟、备份导入导出。

## 怎么编译出 APK

1. 注册 GitHub 账号
2. 新建一个仓库，名字随便
3. 把本项目所有文件按目录结构上传
4. 上传后点上方 Actions 标签
5. 左侧选 Build APK，右侧点 Run workflow
6. 等约 3-5 分钟，出现绿色勾
7. 点进那次运行，最下面 Artifacts 下载 TaskReminder-APK
8. 解压得到 app-release.apk，传到手机安装

## 首次安装后

打开 App，按引导开启：通知、精确闹钟、自启动、电池不优化。
iQOO 尤其要在「设置 -> 电池 -> 后台高耗电」允许本应用。

## 备份与恢复

右上角菜单 -> 导出备份，生成一个 json 文件。
新手机装好 App，右上角菜单 -> 导入备份，选那个 json，任务就回来了。
